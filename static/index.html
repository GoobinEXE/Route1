Identificar o DSi

Confirme câmera, firmware e tipo de cartão no console antes de gravar o SD. A versão da Câmera (com/sem Facebook) escolhe o ficheiro do exploit — não é rede social.

1

Câmera: com ou sem Facebook?

  1. Ligue o DSi e vá ao menu principal.
  2. Abra o app Câmera Nintendo DSi.
  3. Olhe a barra inferior / atalhos da câmera.
Com Facebook — aparece o ícone do Facebook. Use no Passo 1. Típico de EUA/Europa (câmera ~1.4+).
Sem Facebook — sem ícone/opção Facebook. Comum em 1.0–1.3 e na maioria dos DSi japoneses.
2

Versão do sistema

  1. Abra Configurações do Sistema.
  2. Na última página, toque em Dados do Console.
  3. Anote a linha Ver. (ex.: 1.4.5U).

Leitura: número = firmware · letra = região.

U EUA · E Europa · J Japão · A Austrália · C China · K Coreia

3

Modelo e região

  • DSi — corpo menor; slot SD na lateral.
  • DSi XL / LL — telas maiores; mesmo softmod.
  • Etiqueta traseira — TWL-001 (DSi) ou UTL-001 (XL).
  • Menu em japonês — forte indício de região J (geralmente Sem Facebook).
  • DS / DS Lite / 3DS — não usam este softmod.
4

Softmod ou Flashcard?

SD do DSi (slot lateral) — Passos 1–3: exploit, Unlaunch, TWiLight, hiyaCFW.
MicroSD do cartucho — kernel GEi / R4 / DSPico. Não substitui o Unlaunch.
Confira o nome no plástico/PCB. Clones “R4” pedem o kernel do clone.

Referência: dsi.cfw.guide

SD do DSi

Slot lateral — softmod

Cartão do slot lateral do DSi. Faça os passos por ordem na primeira instalação. O Unlaunch é a única etapa que grava na memória interna da consola (no DSi, não neste ecrã).

Passo 1 Memory Pit · dumpTool

Preparar o exploit da Câmera

Escreve no SD o ficheiro do exploit e o dumpTool, para guardar uma cópia da memória interna no DSi.

Quando usar: primeira instalação, antes de abrir a Câmera no DSi.

O que é Memory Pit?
Exploit que abre ao ver o Álbum da Câmera com o cartão SD. O ficheiro tem de corresponder à versão da app Câmera (com ou sem Facebook) — não é rede social.

Versão da app Câmera

Vai escrever no cartão
  • pit.bin (Memory Pit)
  • boot.nds — dumpTool
  • unlaunch-installer.dsi (para o Passo 2)
Passo 2 TWiLight · Unlaunch

Menu de jogos e instalador Unlaunch

Depois do dump da NAND no DSi: instala o TWiLight Menu++ e coloca o instalador seguro do Unlaunch no SD.

Quando usar: após o Passo 1 e o backup no DSi. No update, actualiza o menu sem reinstalar Unlaunch no consol.

O que é Unlaunch?
Bootloader permanente na memória interna do DSi. Este botão só prepara ficheiros no SD; a instalação na consola faz-se no DSi com o instalador.
Vai escrever no cartão
  • TWiLight Menu++ (BOOT.NDS, _nds/, …)
  • unlaunch-installer.dsi na raiz
Se a console já arranca no menu, não volte a abrir o instalador Unlaunch no DSi.
Passo 3 hiyaCFW · SDNAND

Sistema no cartão (hiyaCFW)

Usa o nand.bin do dumpTool para montar o sistema no cartão. O app não grava na memória interna.

Quando usar: Unlaunch já instalado, dump válido, ~512 MB livres. Recomendado após o Passo 2.

O que é hiyaCFW?
Corre o menu do sistema a partir do SD (SDNAND). Depois: Unlaunch → OPTIONS → NO BUTTON → hiyaCFW. Não faça system update.
Detecta automaticamente DT*/nand.bin no cartão seleccionado. Pode demorar vários minutos.
MicroSD do cartucho

Flashcard Slot-1

MicroSD que fica dentro do cartucho — não é o SD lateral do DSi. Não substitui Unlaunch.

GEi Kernel v4.2 EN

Kernel Galaxy Eagle i

Copia o kernel base incluído (vendor/GEiv4.2_EN: _DS_MENU.DAT, _DS_MSHL.NDS, _SYSTEM_, MOONSHL).

Quando usar: está escrito Galaxy Eagle i / GEi no plástico.

Kernel errado = cartucho não arranca. R4 e AceKard pedem outro firmware.
DSPico Pico Launcher

Pacote DSPico

Prepara o microSD com Pico Launcher + Loader oficiais (pins SHA-256).

Quando usar: cartucho DSPico. Gestão completa (jogos, emunand, firmware) no modo DSPico.

Este atalho só escreve o pacote no microSD. Use o separador DSPico para o resto.
R4 / clones: use o (Criar ou Actualizar flashcard → R4) para escolher a pasta do kernel do clone exacto.
